# CCNA Labs

Welcome to my CCNA lab repository.

This repository contains the labs I built while studying for and earning my Cisco CCNA certification. My goal is to document real hands-on networking experience by building, configuring, troubleshooting, and verifying different networking technologies.

Every lab includes:

- Objective
- Network topology
- Device configurations
- Verification commands
- Troubleshooting steps
- Lessons learned

## Technologies

- Cisco IOS
- Cisco Modeling Labs (CML)
- VLANs
- Inter-VLAN Routing
- STP
- EtherChannel
- OSPF
- Static Routing
- ACLs
- NAT
- DHCP
- IPv4 / IPv6
- Wireless
- Network Troubleshooting
